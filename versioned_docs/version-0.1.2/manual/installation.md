# Installation

## Download From GitHub Releases

Download pre-builts from GitHub releases:

https://github.com/rsvim-dev/rsvim/releases

For nightly pre-builts, download the `nightly` tag pre-release:

https://github.com/rsvim-dev/rsvim/releases/tag/nightly

## Build From Source

Build with `cargo`:

```bash
cargo install --locked rsvim
```

For the latest updates, build with `main` branch:

```bash
cargo install --locked rsvim --git https://github.com/rsvim-dev/rsvim.git --branch main
```
